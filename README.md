# BEI Rally Screener Mobile

1. Upload folder ini ke GitHub.
2. Deploy `app.py` melalui Streamlit Community Cloud.
3. Buka URL `*.streamlit.app` dari HP.
4. Tekan `SCAN SEKARANG`.

Data harga/fundamental gratis berasal terutama dari Yahoo Finance. Universe ticker memakai dataset publik yang diperbarui berkala, dengan fallback ticker inti.

Catatan: skor bukan probabilitas dan bukan jaminan return. Untuk penggunaan modal besar, lakukan validasi out-of-sample dan gunakan data resmi/berlisensi untuk keputusan final.
